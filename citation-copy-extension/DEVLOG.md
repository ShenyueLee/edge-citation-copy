# 开发日志

## 2026-11-22 — v1.1.2：超链接只放在标题上

### 反馈的问题

复制到 Word 后，可见的 DOI/URL 链接文本显示为蓝色下划线，但无法点击跳转。

### 修改

- `buildCitationHtml()` 只保留标题一个超链接：
  - 标题使用最简单的 `<a href="干净链接">题名</a>`；
  - 移除 DOI、URL 的可见锚文本，避免复制出额外的蓝色链接；
  - DOI 仍作为普通文本著录；
  - 纯文本版本 `buildCitation()` 仍保留 DOI/URL，保证 GB/T 7714 信息和纯文本场景可用。
- 去掉 `<a>` 上的 `target`、`rel` 属性，减少 Word / WPS 解析差异。
- `manifest.json` 版本升至 `1.1.2`。

### 验证

- 模拟测试确认富文本中只有一个 `<a>` 元素，且锚文本是论文标题，`href` 指向 DOI 或知网干净链接。
- 有 DOI、无 DOI、网页 `[EB/OL]` 三种场景均确认不会残留可见 URL 链接文本。
- `node --check content.js` 通过。

### 注意

- Word 默认需要 **Ctrl + 单击** 打开超链接，直接单击只是定位光标。如果希望单击打开，可在 Word 的“文件 → 选项 → 高级 → 编辑选项”中取消勾选“用 Ctrl + 单击跟踪超链接”。
- 粘贴时需选择“保留源格式”或“合并格式”；如果选择“只保留文本”，超链接会被丢弃。

## 2026-11-22 — v1.1.1：引用字段清理修复

### 反馈的问题

1. 期刊名后出现多余标点，例如 `生态学报 ., 2027`；
2. 机构名被当成作者，例如 `徐凯翔, 王永贵, 1.南京师范大学马克思主义学院, 等`；
3. 知网标题末尾的“附视频”徽标被保留在题名中。

### 修复

- `cleanJournal()` 和 `formatSource()` 增加期刊名尾部标点清理：
  - 去掉末尾的 `.`、`。`、`,`、`，`、`;`、`；`、`:`、`：`、`、`；
  - 去掉标点前的多余空格；
  - 去掉末尾残留的 `》`、`】`、引号等；
  - `生态学报 .` 现在会规范为 `生态学报`。
- 作者过滤新增机构/角色/联系方式识别：
  - `大学`、`学院`、`研究院`、`研究所`、`实验室`、`中心`、`医院`、`公司` 等中文机构词；
  - `University`、`College`、`Institute`、`Department` 等英文机构词；
  - 以 `1.`、`2、` 等编号开头的单位项；
  - 含 `@`、邮箱、地址、教授/主任等角色词的项。
- 作者字符串拆分增加宽松模式：
  - 当逗号或空格分隔的列表中混入单位时，先拆开，再由上述规则过滤单位；
  - 保留“等”标记，确保 `徐凯翔, 王永贵, 等` 这类结果正确。
- 题名清理新增知网徽标移除：
  - 去掉末尾的 `附视频`、`附音频`、`附数据`、`网络首发`、`优先出版`、`增强出版`；
  - 同时支持带括号/方括号的写法，例如 `（附视频）`、`【网络首发】`。
- `manifest.json` 版本升至 `1.1.1`，便于在扩展管理页确认已加载新版本。

### 验证

- `node --check content.js` 通过。
- 使用模拟数据复现并验证了用户提供的两条引用：
  - `生态学报 .` → `生态学报`，输出 `生态学报, 2027.`；
  - `1.南京师范大学马克思主义学院` 不再进入作者列表；
  - 标题末尾 `附视频` 被移除；
  - `徐凯翔, 王永贵, 等` 作者结果正确。
- 真实知网页面仍需在 Edge 中重新加载扩展后手动确认。

## 2026-11-22 — v1.1.0：知网适配与 GB/T 7714-2015 输出

### 反馈的问题

在知网（`kns.cnki.net/kcms2/article/abstract...`）复制时：

1. 作者信息显示为“未知作者”；
2. 链接包含很长的无用参数，例如 `v=...&uniplatform=NZKPT`；
3. 粘贴内容中包含大量多余空格和换行；
4. 引用格式不符合 GB/T 7714-2015（国内论文常用）。

### 本次修改

- 重写元数据提取逻辑，覆盖：
  - `citation_author`、`citation_journal_title`、`citation_volume`、`citation_issue`、`citation_firstpage`、`citation_lastpage`、`citation_doi` 等 Highwire meta；
  - JSON-LD；
  - 知网 DOM：`#authorpart`、`.brief .author`、`.wx-tit .author`、`.top-tip` 等；
  - 通用 `meta[name="author"]`、`[itemprop="author"]`、`[rel="author"]`。
- 作者字符串支持 `;`、`；`、`、`、中文逗号、空格等分隔方式，并清理上标编号、星号。
- 链接清理：
  - 知网优先使用 DOI；
  - 其次使用 canonical；
  - 再次使用 `dbcode` / `dbname` / `filename` 构造稳定链接；
  - 最后回退到当前 URL，并移除 `utm_*`、`uniplatform`、`language` 等跟踪参数。
- 空白清理：
  - 知网页面采用激进模式，合并段内换行、去掉汉字之间的空格；
  - 其他网站保留段落结构。
- 引用格式：
  - 期刊论文输出 `作者. 题名[J]. 刊名, 年, 卷(期): 页码. DOI/URL.`；
  - 网页输出 `作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.`；
  - 超过 3 位作者按 GB/T 7714-2015 截取前 3 位，加“等”或“et al.”。
- 剪贴板同时写入 `text/plain` 和 `text/html`；HTML 中标题和 DOI/URL 为可点击锚文本。
- 只处理用户主动触发的复制事件（`event.isTrusted !== false`），避免干扰页面自己的复制按钮。

### 验证

- `node --check content.js` 通过。
- 使用模拟 DOM 的隔离测试验证了：
  - 知网 4 位作者、期刊、年、卷、期、页码、DOI 的提取；
  - 有 DOI 时生成 DOI 链接；
  - 无 DOI 时生成 `filename` 稳定链接；
  - GB/T 7714 期刊/网页引用格式；
  - 知网空白清理；
  - URL 跟踪参数移除。
- 当前环境无法访问真实知网页面，尚未进行线上页面验证。需要在 Edge 中重新加载扩展后，在知网文章页手动确认作者、期刊、DOI 与粘贴效果。

### 后续可做

- 如果知网改版，优先检查 `#authorpart`、`.brief .author`、`.wx-tit .author`、`.top-tip`。
- 可考虑增加会议论文 `[C]`、学位论文 `[D]` 的专用格式。
- 可考虑提供“列出全部作者”开关，以满足不采用 GB/T 7714 截断规则的场景。
