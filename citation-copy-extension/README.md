# 学术引用复制助手

复制网页文本时，自动在末尾追加来源引用，省去写论文时手动整理标题、作者和链接的麻烦。

## 安装

1. 打开 Edge，在地址栏访问 `edge://extensions/`。
2. 打开左下角的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目文件夹（包含 `manifest.json` 的文件夹）。
4. 安装完成后即可在网页中正常使用。

## 使用

选中文本后按 `Ctrl+C`（或右键复制），粘贴结果示例：

```text
一段来自论文的原文。

[引用信息：论文标题 | 作者：张三、李四 | 链接：https://example.com/article]
```

## 支持的元数据

| 信息 | 来源 |
| --- | --- |
| 网页标题 | `document.title` |
| 网页链接 | 当前页面的完整 URL |
| 作者 | `<meta name="citation_author">`，多个作者用“、”连接；没有时显示“未知作者” |

> 作者信息依赖网页提供的 `citation_author` 元数据。很多学术数据库（如 Google Scholar 收录的期刊页面）会提供该标签，普通网页通常没有，此时作者会显示为“未知作者”。

所有处理都在本地浏览器中完成，不会上传任何数据。
